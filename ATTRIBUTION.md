# Asset attribution

The application ships its runtime asset attribution at
[`public/ATTRIBUTION.md`](public/ATTRIBUTION.md). It covers the CC BY-SA
BodyParts3D / Z-Anatomy derived GLB data and the licences and source links for
the authentic 2D reference plates.

When publishing the built site, retain `ATTRIBUTION.md` from the `public/`
directory alongside the bundled assets.
